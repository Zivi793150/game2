# 🚢 Морской Бой - Современный Фронтенд

Современный React фронтенд для игры "Морской Бой" с красивыми анимациями и морской тематикой.

## ✨ Особенности

- 🎨 **Современный дизайн** с морской тематикой
- 🎭 **Плавные анимации** с Framer Motion
- 📱 **Адаптивный интерфейс** для всех устройств
- ⚡ **Быстрая разработка** с Vite
- 🎯 **Интуитивное управление** кораблями
- 🌊 **Анимированные волны** на фоне

## 🛠 Технологии

- **React 18** - современная библиотека для UI
- **Framer Motion** - плавные анимации
- **Tailwind CSS** - стилизация
- **Lucide React** - красивые иконки
- **Vite** - быстрый сборщик

## 🚀 Установка и запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```

Фронтенд будет доступен по адресу: `http://localhost:3366`

### 3. Сборка для продакшена
```bash
npm run build
```

## 🎮 Как играть

1. **Регистрация/Вход** - создайте аккаунт или войдите в существующий
2. **Главное меню** - выберите режим игры:
   - Найти случайного соперника
   - Сразиться с другом
   - Посмотреть статистику
3. **Расстановка кораблей** - разместите корабли на поле
4. **Битва** - уничтожайте корабли противника!

## 🔧 Конфигурация

### Прокси для API
Фронтенд настроен на проксирование запросов к бэкенду:
- Бэкенд: `http://127.0.0.1:5500`
- Фронтенд: `http://localhost:3366`

### Переменные окружения
Создайте файл `.env`:
```env
VITE_API_URL=http://127.0.0.1:5500
```
